What's filling this folder?

Pick a folder and sizemap draws every directory as a nested mosaic sized by what it holds. Everything happens in this tab; no file leaves your machine.

You can also drop a folder here. Browsers refuse some locations (your home folder itself, system folders), so pick one inside them. Inspired by tobi/disktree.

Keys

space x
mark or unmark the tile you point at (or the selection)
⌘/ctrl-click
mark without moving the selection
enter / double-click
open that directory
⌫ esc
go up one directory
←↑↓→ hjkl
move between tiles at this level
tab
next largest sibling (shift for previous)
[ ]
draw fewer or more levels at once
/
filter by name: only matches keep their colour, esc clears
t
cycle size / file count / age
i
include or skip hidden entries
c
review the marked list
0
back to the scanned folder
r
scan again
o
open another folder
Sizes are logical file sizes: the browser can't see disk blocks, clones or hard links.
